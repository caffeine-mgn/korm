# korm

ORM для Kotlin Multiplatform поверх пула `kdatabase`.

## Что есть

| Слой | Файл |
|---|---|
| Аннотации | `Annotations.kt` — `@TableName`, `@ColumnName`, `@Id`, `@AutoGenerated`, `@Index`, `@Embedded`, `@ColumnType` |
| Описание сущности | `EntityDescription.kt` — разбор `SerialDescriptor` |
| Генератор SQL | `SqlBuilder.kt` — insert/update/select/upsert/delete/createTable |
| Доступ | `Orm.kt` — CRUD через пул, транзакции |
| Кодирование | `ValueEncoder.kt`, `ResultSetDecoder.kt` |

## Почему на `kotlinx.serialization`, а не на рефлексии

Рефлексии в Kotlin/Native нет. Единственный переносимый источник метаданных —
`SerialDescriptor`, который генерирует плагин `kotlinx.serialization`.
Аннотации помечены `@SerialInfo`, чтобы попадать в дескриптор.

Готового KMP-ORM под native и JS не существует: Exposed и Ktorm — JVM-only,
SQLDelight — генератор кода из SQL, а не CRUD по объектам.

## Именованные параметры

Генерируется `:name`, а не `$1` или `?`: ORM не знает, какая СУБД под ней.
Перевод в позиционный вид — работа драйвера (в `kpostgres` адаптере это
`ParamConverter`).

**Параметр называется по имени поля, колонка — по имени в БД.** `@ColumnName`
на `email` даёт `:email` в параметрах и `email_addr` в SQL. Путать нельзя:
значения подставляются по имени параметра.

## Плоско, без связей

Одна сущность — одна таблица. Связей (`@OneToMany` и подобных) нет: они
тянут за собой сессии, кэш первого уровня и unit of work. Для JOIN —
`Orm.select` с готовым SQL.

## Проверка

```
./gradlew :jvmTest :linuxX64Test
```

23 теста на каждой платформе, БД не нужна: генерация SQL и кодирование
значений — чистые функции от дескриптора.

## Грабли, найденные при разработке

**`String.format` в Kotlin 2.4 — только JVM.** Тесты с hex-дампом не
компилируются в native. Замена: `toString(16)` с дополнением.

**Запятые в именах тестов запрещены в native.** `fun \`поля, порядок\``
не компилируется; писать без запятых.

**`AbstractDecoder` не объявляет `descriptor`.** His нет в интерфейсе —
`override` невозможен, дескриптор хранится отдельным полем.

**`@Retention(BINARY)` обязательна.** `RUNTIME` в native не поддерживается,
аннотация просто исчезнет из дескриптора.
